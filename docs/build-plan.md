# Build plan

- Phase A adds the pinned Agent-Native Chat foundation, PostgreSQL migrations and Northlight Studio seed, typed schedule reads, and the Bryntum resource timeline.
- Phase B adds merchant policy approval, the durable outbound queue, scoped demo inboxes, and catalog-based offer revision from a live reply.
- Phase C adds exclusive holds, PayPal sandbox checkout, capture verification, webhooks, reconciliation, and the merchant refund path.
- Phase D verifies the merchant and customer experience, the PostgreSQL race and retry cases, and the sandbox checkout when configured. The setup guide and demo script cover operation and handoff.
